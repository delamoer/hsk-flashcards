“把”字句“主语 + 把 + 宾语 + 动词 + 了”把字句把 sentence
bǎ zì jù: zhǔyǔ + bǎ + bīnyǔ + dòngcí + le

Use 把 + object + verb + 了 when a specific object has been dealt with or an action on it is completed.

结构 Structure主语 + 把 + 宾语 + 动词 + 了Subject + bǎ + Object + Verb + le = have dealt with the object (completed)
我已经把票买了。
Wǒ yǐjīng bǎ piào mǎi le.
I have bought the ticket.
他把车卖了。
Tā bǎ chē mài le.
He sold the car.
我们先把饭吃了吧。
Wǒmen xiān bǎ fàn chī le ba.
Let us eat the meal first.
※ 这里的动词后可以直接带“了”，强调对明确宾语的处置已经完成。The verb can take 了 directly, stressing that the specific object has been dealt with.
