“首先……其次……”表示顺序顺序结构Sequence structure
shǒuxiān ... qícì ...

Use 首先…其次… to organize points: “first…, second…”.

结构 Structure首先 + 第一点；其次 + 第二点shǒuxiān + point 1; qícì + point 2 = first … second …
首先要认真听，其次要多练习。
Shǒuxiān yào rènzhēn tīng, qícì yào duō liànxí.
First listen carefully; second, practice more.
首先谢谢大家，其次我想说一下计划。
Shǒuxiān xièxie dàjiā, qícì wǒ xiǎng shuō yíxià jìhuà.
First, thank you; second, I want to talk about the plan.
买房首先看位置，其次看价格。
Mǎi fáng shǒuxiān kàn wèizhi, qícì kàn jiàgé.
When buying a home, first look at location, then price.
※ 常用于比较正式地列出两点或多点。Used to list two or more points fairly formally.
