语法汇总 Grammar◇倍数表达“倍”
倍数表达“倍”数量表达Quantity
bèi

Use 倍 to say “times as much/many”.

结构 StructureA 是 B 的 + 数字 + 倍；增加/多 + 数字 + 倍A shì B de + number + bèi; zēngjiā/duō + number + bèi = A is N times B / increased N-fold
这个房间是那个房间的两倍大。
Zhège fángjiān shì nàge fángjiān de liǎng bèi dà.
This room is twice as big as that room.
今年的学生人数是去年的两倍。
Jīnnián de xuésheng rénshù shì qùnián de liǎng bèi.
The number of students this year is twice last year’s.
这台电脑的价格是那台的三倍。
Zhè tái diànnǎo de jiàgé shì nà tái de sān bèi.
This computer costs three times as much as that one.
※ 注意英语和汉语对倍数理解有时不同；初学先掌握“A是B的两倍”。Multiples work differently in English/Chinese; first master "A 是 B 的两倍".
