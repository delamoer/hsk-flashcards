语法汇总 Grammar◇假设复句“要是……，就……”
假设复句“要是……，就……”条件复句Conditional
jiǎshè fùjù yàoshi ... jiù ...

Use 要是…就… for “if…then…”. 要是 is common in spoken Chinese.

结构 Structure要是 + 条件，就 + 结果yàoshi + condition, jiù + result = if …, then … (spoken)
要是明天下雨，我们就不去了。
Yàoshi míngtiān xià yǔ, wǒmen jiù bú qù le.
If it rains tomorrow, we will not go.
要是你累了，就休息一下。
Yàoshi nǐ lèi le, jiù xiūxi yíxià.
If you are tired, take a rest.
要是有时间，我就去看你。
Yàoshi yǒu shíjiān, wǒ jiù qù kàn nǐ.
If I have time, I will go see you.
※ 和“如果……就……”意思接近，“要是”更口语。Close in meaning to 如果…就…; 要是 is the more colloquial of the two.
