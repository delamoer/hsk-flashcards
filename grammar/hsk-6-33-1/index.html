语法汇总 Grammar◇固定格式“A的A，B的B”
固定格式“A的A，B的B”列举结构Enumeration
A de A, B de B

Use A的A，B的B to list different people/things doing or showing different things.

结构 Structure动词/形容词 + 的 + 同一动词/形容词，……Verb/Adj + de + same Verb/Adj, … = some …, some … (listing what everyone is doing)
下课以后，看书的看书，聊天的聊天。
Xiàkè yǐhòu, kàn shū de kàn shū, liáotiān de liáotiān.
After class, some read and some chat.
进了果园，红的红，绿的绿，漂亮极了。
Jìnle guǒyuán, hóng de hóng, lǜ de lǜ, piàoliang jí le.
In the orchard, some fruit is red and some green; it is beautiful.
周末大家忙自己的，运动的运动，休息的休息。
Zhōumò dàjiā máng zìjǐ de, yùndòng de yùndòng, xiūxi de xiūxi.
On weekends, everyone does their own thing: some exercise, some rest.
※ 常用于口语，把同一场景中的不同情况并列列出来。Common in speech; lists the different things going on in the same scene side by side.
