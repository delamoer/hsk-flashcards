语法汇总 Grammar◇递进复句“不仅/不光……，还/而且……”
递进复句“不仅/不光……，还/而且……”递进复句Progressive clause
dìjìn fùjù bùjǐn/bùguāng ... hái/érqiě ...

Use 不仅/不光…还/而且… for “not only…but also…”.

结构 Structure不仅/不光 + A，还/而且 + Bbùjǐn/bùguāng + A, hái/érqiě + B = not only A but also B
手机不仅能打电话，还能上网。
Shǒujī bùjǐn néng dǎ diànhuà, hái néng shàngwǎng.
A phone can not only make calls but also go online.
她不光会说中文，而且会写汉字。
Tā bùguāng huì shuō Zhōngwén, érqiě huì xiě Hànzì.
She can not only speak Chinese but also write Chinese characters.
这个软件不仅方便，而且很安全。
Zhège ruǎnjiàn bùjǐn fāngbiàn, érqiě hěn ānquán.
This software is not only convenient but also safe.
※ “不光”更口语，“不仅”口语和书面语都常用。不光 is more colloquial; 不仅 works in both speech and writing.
