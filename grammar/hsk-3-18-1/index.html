“只要……，就……”表示充分条件条件复句Conditional
zhǐyào ... jiù ...

Use 只要…就… to mean “as long as… then…”.

结构 Structure只要 + 条件，就 + 结果zhǐyào + condition, jiù + result = as long as …, then …
只要你努力，就会进步。
Zhǐyào nǐ nǔlì, jiù huì jìnbù.
As long as you work hard, you will improve.
只要不下雨，我们就去。
Zhǐyào bú xià yǔ, wǒmen jiù qù.
As long as it does not rain, we will go.
只要有时间，我就运动。
Zhǐyào yǒu shíjiān, wǒ jiù yùndòng.
As long as I have time, I exercise.
※ “只要”强调这个条件一满足，后面的结果就可以发生。只要 stresses that once the condition is met, the result can happen.
