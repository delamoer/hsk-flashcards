语法汇总 Grammar◇指示代词“此”
指示代词“此”指示代词Demonstrative pronoun
zhǐshì dàicí cǐ

此 means “this / this one”. It is mainly used in formal or written Chinese.

结构 Structure此 + 名词；从此；因此等固定搭配cǐ + Noun; cóngcǐ; yīncǐ and other set phrases = this (formal): from now on, therefore …
此次活动有很多学生参加。
Cǐ cì huódòng yǒu hěn duō xuésheng cānjiā.
Many students took part in this event.
此人是我的同事。
Cǐ rén shì wǒ de tóngshì.
This person is my colleague.
请把此材料交给老师。
Qǐng bǎ cǐ cáiliào jiāo gěi lǎoshī.
Please give this material to the teacher.
※ “此”较正式，日常口语通常用“这/这个”。此 is formal; everyday speech uses 这 / 这个.
