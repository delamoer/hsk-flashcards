语法汇总 Grammar◇又……又……
又……又……并列结构Coordinate structure
yòu ... yòu ...

Use 又…又… to say something has two qualities at the same time: “both…and…”.

结构 Structure主语 + 又 + 形容词1 + 又 + 形容词2Subject + 又 (yòu, both) + Adjective 1 + 又 (yòu, and) + Adjective 2
这个苹果又大又甜。
Zhège píngguǒ yòu dà yòu tián.
This apple is both big and sweet.
这家饭馆又干净又便宜。
Zhè jiā fànguǎn yòu gānjìng yòu piányi.
This restaurant is both clean and inexpensive.
这件衣服又好看又舒服。
Zhè jiàn yīfu yòu hǎokàn yòu shūfu.
This piece of clothing is both pretty and comfortable.
※ 两个并列的特点通常属于同一个主语；主要练常用形容词搭配。The two qualities usually belong to the same subject. Practice with common adjective pairs.
