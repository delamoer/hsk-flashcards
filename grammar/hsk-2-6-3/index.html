“因为……所以……”表示原因和结果复句Complex sentence
yīnwèi ... suǒyǐ ...

Use 因为…所以… for “because… so…”.

结构 Structure因为 + 原因，所以 + 结果yīnwèi + Reason, suǒyǐ + Result = “Because ..., so ...”
因为下雨，所以我没去。
yīnwèi xiàyǔ, suǒyǐ wǒ méi qù.
Because it rained, I did not go.
因为他很忙，所以没来。
yīnwèi tā hěn máng, suǒyǐ méi lái.
Because he was busy, he did not come.
因为我喜欢汉语，所以每天学习。
yīnwèi wǒ xǐhuan hànyǔ, suǒyǐ měitiān xuéxí.
Because I like Chinese, I study every day.
※ 口语里有时可省略“因为”或“所以”，初学先掌握完整结构。In speech 因为 or 所以 can be dropped; beginners should learn the full pattern first.
