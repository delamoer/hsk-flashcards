转折复句“……×是×，就是/不过……”转折复句Adversative clause
zhuǎnzhé fùjù ... X shì X, jiùshì/bùguò ...

Use “X是X，不过/就是…” to admit one point first, then add a limitation.

结构 Structure主语/事物 + X是X，不过/就是 + BSubject/thing + X shì X, búguò/jiùshì + B = X it may be, but …
这个手机好是好，不过有点儿贵。
Zhège shǒujī hǎo shì hǎo, búguò yǒudiǎnr guì.
This phone is good, but it is a little expensive.
北京大是大，就是有时候太堵。
Běijīng dà shì dà, jiùshì yǒu shíhou tài dǔ.
Beijing is big, but sometimes traffic is too heavy.
这家店远是远，不过东西很便宜。
Zhè jiā diàn yuǎn shì yuǎn, búguò dōngxi hěn piányi.
This shop is far, but things are cheap.
※ 前半句先承认某个特点，后半句指出限制、问题或不同方面。The first clause concedes a point; the second raises a limit, a problem, or another side.
