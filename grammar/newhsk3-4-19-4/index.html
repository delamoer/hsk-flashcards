“把”字句“主语 + 把 + 宾语 + 动词 + 时量补语”把字句把 sentence
bǎ zì jù: zhǔyǔ + bǎ + bīnyǔ + dòngcí + shíliàng bǔyǔ

Use 把 + object + verb + duration to say how long you do the action to that object.

结构 Structure主语 + 把 + 宾语 + 动词 + 时间长度Subject + bǎ + Object + Verb + a length of time = do sth to the object for …
我把这本书看了两个小时。
Wǒ bǎ zhè běn shū kàn le liǎng ge xiǎoshí.
I read this book for two hours.
他把车开了三个小时。
Tā bǎ chē kāi le sān ge xiǎoshí.
He drove the car for three hours.
我把房间打扫了半个小时。
Wǒ bǎ fángjiān dǎsǎo le bàn ge xiǎoshí.
I cleaned the room for half an hour.
※ 时量补语说明动作持续多久；“把”的宾语仍然是明确、具体的。The duration complement says how long; the 把 object is still specific.
