语法汇总 Grammar◇连词“要是”
连词“要是”连词Conjunction
yàoshi

Use 要是…就… as a spoken way to say “if… then…”.

结构 Structure要是 + 条件，就 + 结果yàoshi + condition, jiù + result = if …, then … (spoken)
要是明天下雨，我们就不去了。
Yàoshi míngtiān xià yǔ, wǒmen jiù bú qù le.
If it rains tomorrow, we will not go.
要是你累了，就休息一下。
Yàoshi nǐ lèi le, jiù xiūxi yíxià.
If you are tired, take a rest.
要是有问题，就给我打电话。
Yàoshi yǒu wèntí, jiù gěi wǒ dǎ diànhuà.
If there is a problem, call me.
※ “要是”比“如果”更口语。要是 is more colloquial than 如果.
