语法汇总 Grammar◇指示代词“任何”
指示代词“任何”代词Pronoun
zhǐshì dàicí rènhé

Use 任何 to mean “any / whichever”. It usually comes before a noun.

结构 Structure任何 + 名词；任何人/任何时候/任何地方rènhé + Noun; rènhé rén / rènhé shíhou / rènhé dìfang = any …; anyone / any time / anywhere
任何人都可以参加。
Rènhé rén dōu kěyǐ cānjiā.
Anyone can take part.
有任何问题都可以问我。
Yǒu rènhé wèntí dōu kěyǐ wèn wǒ.
You can ask me if you have any questions.
任何时候都不要放弃。
Rènhé shíhou dōu búyào fàngqì.
Do not give up at any time.
※ “任何”强调没有限制；后面常接“人、问题、时候、地方”等。任何 stresses that there is no limit at all; it is usually followed by 人 / 问题 / 时候 / 地方.
