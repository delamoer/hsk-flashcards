语法汇总 Grammar◇“只有……，才……”表示必要条件
“只有……，才……”表示必要条件条件复句Conditional
zhǐyǒu ... cái ...

Use 只有…才… to mean “only if… then…”. The first condition is necessary.

结构 Structure只有 + 条件，才 + 结果zhǐyǒu + condition, cái + result = only if …, then …
只有多练习，汉语才会进步。
Zhǐyǒu duō liànxí, Hànyǔ cái huì jìnbù.
Only with more practice will your Chinese improve.
只有有票，才能进去。
Zhǐyǒu yǒu piào, cái néng jìnqu.
Only if you have a ticket can you go in.
只有周末，我才有时间运动。
Zhǐyǒu zhōumò, wǒ cái yǒu shíjiān yùndòng.
Only on weekends do I have time to exercise.
※ “只要……就……”=条件够了就行；“只有……才……”=这个条件是必须的。只要…就… = enough condition; 只有…才… = a necessary condition.
